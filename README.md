# MLIP

Welcome to the **MLIP Tutorials**!

These tutorials are designed to guide you step by step into the field of **Machine Learning Interatomic Potentials (MLIPs)** and their applications in materials science.

The main objectives are to help you:

1. **Develop an MLIP model**
2. **Apply an MLIP model** to materials simulations
3. **Explore potential research directions** in materials science using MLIP-based approaches

## Repository Structure

Currently, this repository contains two main folders:

### `Tutorials`

This folder introduces the fundamentals of **MLIP development** and provides guidance on possible **research approaches**.

The tutorials are intended to help you understand the general workflow, including model development, application, analysis, and how MLIPs can be integrated into materials science research.

### `SIMMAT`

This folder contains tutorials prepared for the **SIMMAT Erasmus+ KA171 School — Simulation Tools for Materials Design**.

The school is organized through collaboration between:

- **Université Paris-Saclay, France**
- **Vietnam National University – Hanoi University of Science (VNU-HUS), Vietnam**
- **Vietnam National University – Ho Chi Minh City University of Science (VNU-HCMUS), Vietnam**

Please check the `SIMMAT` folder for more details about the course materials, practical exercises, and simulation tutorials.
